# 智能考试系统

基于 SSM 框架的智能题库与自适应组卷系统 —— 毕业设计项目

---

## 📖 项目简介

本项目是一款面向高校教学的智能考试与题库管理系统，致力于解决传统组卷效率低、题目重复率高、无法因材施教等教学痛点。

系统采用**自适应组卷算法**，根据学生历史答题数据与知识点掌握度，动态调整题目难度与知识点权重，实现真正意义上的个性化测评。

---

## ✨ 核心功能

### 📚 题库管理
- 支持多题型（单选、多选、判断、简答）
- 知识点标签管理，精准关联题目
- 批量导入/导出题目

### 📝 智能组卷
- 支持手动组卷与自动组卷
- 多种组卷策略：随机组卷、按知识点组卷、自适应组卷
- 自动校验试卷难度分布

### 🖥 在线考试
- 学生在线答题，实时计时
- 自动阅卷（客观题）
- 考试记录与成绩查看

### 📊 自适应测评
- 基于IRT（项目反应理论）的能力评估
- 动态调整后续题目难度
- 精准评估学生知识点掌握度

### 👨‍🏫 成绩管理
- 成绩统计与分析
- 班级/个人成绩对比
- 成绩导出（Excel）
